Crear una voz

VoiceDesign 1.7B

Para inventar una voz no necesitas elegir Ryan, Vivian ni ninguna voz incluida. Se utiliza VoiceDesign.

Escribe la muestra en este idioma. Español no implica automáticamente acento de España.

Describe el timbre, la edad aproximada, el acento y la forma de hablar. La descripción orienta el resultado; puedes crear varias muestras.

Usa un texto de unos 10–20 segundos. Al crear la muestra se cambia de modelo; después se vuelve a preparar el motor de clonación.

Opciones de generación

La semilla ayuda a repetir una prueba; distintos modelos producen resultados diferentes. La temperatura y Top P/Top K actúan cuando el muestreo está activo.

ESCUCHA Y MIDE

Compara con el mismo texto.

En Generar audio elige una voz e idioma y pulsa Comparar. Se prueba cada modelo dos veces: carga nueva y repetición.

RTF = segundos de síntesis / segundos de audio. Menor es más rápido. La carga se mide aparte. Las notas de calidad son tuyas, tras escuchar; los tiempos no determinan la calidad.
