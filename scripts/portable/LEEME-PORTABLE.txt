VOZ ESTUDIO · WINDOWS NVIDIA · PAQUETE SIN DESCARGAS ADICIONALES

REQUISITOS
Windows de 64 bits, GPU NVIDIA y controlador compatible con CUDA 12.8.
La GPU utilizada para probarlo es una RTX 4090 Laptop de 16 GB.
No necesita instalar Python, pip, Qwen, Faster Qwen3-TTS ni Whisper.
El controlador de NVIDIA y los componentes del sistema operativo no se incluyen.
Reserva al menos 25 GB libres durante la preparación (partes + extracción).

PREPARAR LA DESCARGA
1. Descarga Preparar-Voz-Estudio.zip y TODAS las partes .zip.001, .zip.002…
2. Coloca las partes en una carpeta y extrae Preparar-Voz-Estudio.zip allí mismo.
3. Abre Preparar.cmd. Comprueba las huellas, une las partes y extrae el paquete.
   Esta preparación utiliza su propio Python incluido y no accede a Internet.
   No sobrescribe una carpeta de una instalación anterior.

USAR
Abre Iniciar.cmd dentro de VozEstudio-…-Windows-NVIDIA.
La aplicación se abre en http://127.0.0.1:3020.
Si el puerto está ocupado, ejecuta Iniciar.cmd --port 3021.
La primera generación prepara el modelo. Después queda cargado en la GPU.
Detener.cmd cierra el servidor. Cerrar la pestaña no lo detiene.
Comprobar.cmd verifica todas las huellas y comprueba las bibliotecas incluidas.

DATOS Y TRASLADO
Las voces, textos y MP3 se guardan en data, junto a los JSON.
El paquete público está vacío de voces y de grabaciones personales.
Para llevar tus voces y audios a otro PC, detén la aplicación y copia data.
Puedes mover la carpeta completa; sus rutas no dependen del ordenador de origen.
No se garantiza la misma velocidad en otros equipos.

CONTENIDO
runtime: Python y bibliotecas reales, no una copia de un entorno virtual.
app: código de Voz Estudio.
models: Qwen3-TTS 0.6B, tokenizador y Whisper small, con revisiones fijadas.
licenses y metadatos de paquetes: licencias de los componentes incluidos.
bundle-manifest.json: tamaños y SHA256 de los archivos distribuidos.

Código y actualizaciones: https://github.com/mcd3/voz-estudio
Solo ofrece voz natural; no incluye control efectivo de risas ni llanto.
